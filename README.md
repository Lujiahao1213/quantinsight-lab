# QuantInsight Lab

[Live Demo](https://quantinsight-lab.onrender.com/)

QuantInsight Lab is an AI-assisted Flask-based financial quantitative analysis platform for user-uploaded market datasets.

QuantInsight Lab v2.4 supports robust CSV/Excel ingestion, Data Agent v2 column mapping, data quality scoring, strategy backtesting, strategy comparison, ML single-model analysis, ML compare-all-models, and a consolidated Report v2.

This project was developed with the assistance of Cursor AI. The product idea, feature planning, testing, debugging, UI direction, and final integration were guided by the project owner.

---

## 1. Project Overview

### What this project does

QuantInsight Lab provides an end-to-end financial analysis workflow in a browser-based interface.

It transforms raw uploaded historical market data into standardized analysis-ready data, then supports:

- Market data inspection
- Data quality evaluation
- Technical strategy backtesting
- Strategy comparison
- Machine learning model evaluation
- Consolidated report generation

### Why it was built

This project was built as a practical, modular, and portfolio-ready quantitative research platform.

It combines robust data ingestion, technical strategy evaluation, and ML benchmarking in one lightweight Flask web application.
